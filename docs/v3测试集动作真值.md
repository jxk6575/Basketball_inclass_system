# v3 测试集 — 各组动作真值（Ground Truth）

> 用途：v3 迭代的效果验证基准。  
> 数据：`data/test_data_v3/{g}-{c}.mkv`（group0 为注册切片，见同目录 README）。  
> 更新：2026-08-06

## 总原则

- **每个 group 只出现下文列出的动作**，不存在未提及的动作类型。
- 验证时以「召回这些动作、且不要大量误检其它类型」为准。
- group0 仅用于身份注册，不做动作评测。

## 时间轴约定

| 项 | 约定 |
|----|------|
| 锚点机位 | **cam_03**（下列时间均相对该机位本地时间） |
| 人物代号 | `A` / `B` / `C` / `D`（与具体 `stu_XX` 的映射由评测脚本决定） |
| 时间单位 | 秒（`s`） |

### 动作缩写

| 缩写 | 规范标签 | 含义 |
|------|----------|------|
| `ft` | `free_throw` | 站定罚篮式出手（无明显纵跳） |
| `js` | `jump_shot` | 跳投（与罚篮类似，但明显跳起） |
| `layup` | `layup` | 上篮（助跑近筐） |
| `tt` | `triple_threat` | 三威胁 / **突破**（本系统无独立 dribble 标签） |
| `pass` | `pass` | 传球 |

## 验证建议

1. **注册（group0）**：从 **cam_02** 顺序正面注册，应稳定得到多名学生 gallery（`stu_00`…）。
2. **group1+**：以各组时间轴为准；输出目录建议 `data/outputs/v3/`。
3. **时间同步**：先对齐 `data/test_data_v3/sync/group_XX.json`，再跑批处理。

## 相关入口

```bash
# 数据目录
ls data/test_data_v3/{0,1}-*.mkv

# 可视化时间对齐
PYTHONPATH=. python scripts/sync_group_gui.py --data-dir data/test_data_v3 --group 1

# v3 全量批处理（默认 --mode full，渲 viz 视频 + dashboard；勿默认 --skip-viz）
PYTHONPATH=. python scripts/run_v3_testset.py --groups all

# 仅补渲已有 session 的 viz/dashboard（不删 motion/report JSON）
PYTHONPATH=. python scripts/run_v3_testset.py --groups 1,2,3,4,5 --rerender-viz

# 注册机位（v3）：configs/cameras.yaml → enrollment_camera: cam_02
```
