# 球场控制点标定（cam_01–03）

目标：用已知 3D 坐标的球场线交点估计各相机 **内参 K、畸变、外参 (R,t)**，并得到相机光心的**世界坐标**，为真 3D 三角化做准备。

## 各相机标注点（已写入配置）

配置：`configs/calibration/court_landmarks_fiba.yaml` → `annotation_order_by_camera`

| 相机 | 标注点 |
|------|--------|
| **cam_01** | 底线右角、限制区底线右、限制区罚球线右、罚球圈-罚球线右交点、罚球圈-罚球线左交点 |
| **cam_02** | 底线左角、限制区底线左、限制区底线右、限制区罚球线左、限制区罚球线右、罚球圈右/左交点 |
| **cam_03** | 中圈-中线右交点、**中线右边线交点**、限制区罚球线右、罚球圈-罚球线右/左交点 |

- cam_01/02：**≥5–7 点**，可估计焦距 + 径向畸变  
- cam_03：**5 点**（中圈右交点 + 中线右边线交点 + 限制区/罚球圈点）；点不足时复用共享内参  
- 机位先验：cam_03 水平位置约 (−6.4, −0.15)，三机同高、边线机在场外（见 yaml `camera_pose_priors`）

坐标系：原点 = **进攻端底线中点**，+x 向右，+y 指向中线，+z 向上。  
完整 xyz：`configs/calibration/court_landmarks_fiba.yaml`。非 FIBA 场地请改 `xyz`。

## 推荐流程

```bash
# 0) 查看各相机要点清单
python scripts/calibrate_court.py list-landmarks

# 1) 从空场/少人视频抽静帧（选线最清晰的一帧）
python scripts/calibrate_court.py extract-frames \
  --videos data/test_data_v1 --group 1 \
  --out data/calibration/frames

# 2) 按 cam_01 → cam_02 → cam_03 依次 GUI 标注
python scripts/calibrate_court.py annotate-all \
  --frames data/calibration/frames \
  --ann data/calibration/annotations.json

# 或单相机：
python scripts/calibrate_court.py annotate \
  --image data/calibration/frames/cam_01.jpg --camera cam_01 \
  --ann data/calibration/annotations.json

# 3) 求解内参+畸变+外参，导出世界坐标
python scripts/calibrate_court.py solve \
  --ann data/calibration/annotations.json \
  --out data/calibration/v2_4cam_zoned
```

## 求解在做什么

1. **内参 + 畸变**（平面标定）：对点≥6 的相机用 `calibrateCamera`（固定纵横比、零切向、估 k1/k2）  
2. **弱相机**（如 cam_03 仅 4 点）：共享 cam_01/02 的 K、dist  
3. **外参**：平面 IPPE + LM 精炼 → `R, t`  
4. **手性修正（Z>0）**：球场点共面 (z=0)，PnP 有两解；翻转 v 求解并导出 fy&lt;0  
5. **机位先验**：cam_03 水平位置固定在「底线-三分线左交点 +右0.20m、外0.15m」≈(−6.4,−0.15)；cam_01/02 强制在边线外侧；三机 **共享同一高度**  
6. **相机世界坐标**：光心 \(C = -R^{\top} t\)（米）  

重投影误差目标：平均 **&lt; 3–5 px**。

去畸变时请用 `|fy|`（代码里 `undistort` 段已处理）。

## 输出

`data/calibration/v2_4cam_zoned/`

| 文件 | 内容 |
|------|------|
| `cameras.json` | 完整结果 |
| `cam_01.json` … | 各相机 K、dist、R、t、重投影误差 |
| `camera_centers_world.json` | **三相机光心世界坐标** |
| `README.txt` | 去畸变用法提示 |

去畸变示例：

```python
import cv2, json, numpy as np
cam = json.loads(open("data/calibration/v2_4cam_zoned/cam_01.json").read())
K = np.array(cam["intrinsics"]["camera_matrix"], dtype=float)
K[1, 1] = abs(K[1, 1])  # 去畸变用 |fy|
D = np.array(cam["intrinsics"]["dist_coeffs"])
newK = np.array(cam["undistort"]["new_camera_matrix"])
und = cv2.undistort(frame, K, D, None, newK)
```

## 精度提示

- 尽量选**线清晰、人少遮挡**的帧；交点点在线中央而非模糊边缘  
- 镜头变焦/云台移动后需重标  
- 有棋盘时可先做内参，再把 `intrinsics` 写入 annotations / cam json  
- 教室半场尺寸非 FIBA 时务必实测改 yaml
