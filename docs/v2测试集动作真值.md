# v2 测试集 — 各组动作真值（Ground Truth）

> 用途：后续版本迭代的效果验证基准。  
> 数据：`data/test_data_v2/{g}-{c}.mkv`（group0 为注册切片，见同目录 README）。  
> 更新：2026-07-24

## 总原则

- **每个 group 只出现下文列出的动作**，不存在未提及的动作类型。
- 验证时以「召回这些动作、且不要大量误检其它类型」为准。
- group0 仅用于身份注册，不做动作评测。

## 分组说明

| Group | 文件 | 内容（真值） | 允许的规范标签 |
|-------|------|--------------|----------------|
| **0** | `0-*.mkv` | 注册：每人在 cam_01 前拍正面（由原 group1 前 90s 切出） | —（无动作） |
| **1** | `1-*.mkv` | **投篮**（轮流罚篮 / 站定出手） | `free_throw` |
| **2** | `2-*.mkv` | **上篮** | `layup` |
| **3** | `3-*.mkv` | **突破 + 上篮** | `triple_threat` · `layup` |
| **4** | `4-*.mkv` | **突破 + 进球**（跳投 / 罚篮 / 上篮） | `triple_threat` · `jump_shot` · `free_throw` · `layup` |
| **5** | `5-*.mkv` | **突破 + 投篮**（跳投 / 罚篮） | `triple_threat` · `jump_shot` · `free_throw` |
| **6** | `6-*.mkv` | **6 人 3 组传球** | `pass` |

### 标签说明

| 标签 | 含义 |
|------|------|
| `free_throw` | 站定罚篮式出手（无明显纵跳） |
| `jump_shot` | 跳投（与罚篮类似，但明显跳起） |
| `layup` | 上篮（助跑近筐） |
| `triple_threat` | 三威胁 / **突破**（本系统无独立 dribble 标签） |
| `pass` | 传球 |

## 验证建议

1. **注册（group0）**：应稳定得到 **6** 名学生 gallery（`stu_00`…`stu_05`）。
2. **group1**：以 `free_throw` 为主（站定罚篮式出手）；不应出现 `pass` / `layup` / `triple_threat`。
3. **group2**：以 `layup` 为主。
4. **group3**：`triple_threat` + `layup` 共存；无纯站定罚篮为主的片段预期。
5. **group4**：突破后出现投篮族或上篮，且 cam_04 应有 make/miss。
6. **group5**：突破 + 跳投/罚篮；无上篮为主预期。
7. **group6**：以 `pass` 为主；应能区分多组传球参与者（依赖 ReID）。

## 相关入口

```bash
# 注册 + group1
PYTHONPATH=. python scripts/run_v2_testset.py --groups 0,1 --mode full

# 全组
PYTHONPATH=. python scripts/run_v2_testset.py --groups all --mode full
```

输出：`data/outputs/v2/group_0X/`（`summary.json` / `report.json` / `viz/`）。
