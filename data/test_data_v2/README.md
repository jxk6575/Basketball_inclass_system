# test_data_v2

四机位课堂录像（`{group}-{cam}.mkv`，cam=`1..4` → `cam_01..04`）。

## 切分说明（2026-07-24）

原始 **group1** 整段约 215s：前 **90s（1.5 分钟）** 为注册相关，之后为轮流投篮。已拆为：

| 组 | 文件 | 内容 | 时长（约） |
|----|------|------|------------|
| **group0** | `0-1.mkv` … `0-4.mkv` | 每人在 **cam_01** 前拍正面注册 | ~90s |
| **group1** | `1-1.mkv` … `1-4.mkv` | 轮流投篮（罚篮/跳投） | ~126s |
| group2–6 | `2-*` … `6-*` | 见 [docs/v2测试集动作真值.md](../../docs/v2测试集动作真值.md) | — |

完整未切原始片保留在 `_archive_full/1-*-full.mkv`（可删，仅作备份）。

## 动作真值（验证基准）

详见 **[docs/v2测试集动作真值.md](../../docs/v2测试集动作真值.md)**：

| Group | 真值 |
|-------|------|
| 1 | 投篮（`free_throw` / `jump_shot`） |
| 2 | 上篮 |
| 3 | 突破 + 上篮 |
| 4 | 突破 + 进球（跳投/罚篮/上篮） |
| 5 | 突破 + 投篮（跳投/罚篮） |
| 6 | 6 人 3 组传球 |

## 使用约定

- **注册 gallery**：从 **group0 / cam_01** 做顺序正面注册，得到多名 `student_id`。
- **group1+ 分析**：复用 group0 gallery（或同 session 注册结果）做 ReID 跟踪与动作切分。
- 批处理入口：`scripts/run_v2_testset.py`。
